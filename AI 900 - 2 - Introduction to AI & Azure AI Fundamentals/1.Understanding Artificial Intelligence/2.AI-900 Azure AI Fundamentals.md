# 1. What is Artificial Intelligence (AI)?

## Definition

Artificial Intelligence (AI) is the field of computer science focused on creating machines that can perform tasks that normally require human intelligence.

AI enables computers to:

- Learn from experience
- Understand information
- Recognize patterns
- Make decisions
- Respond intelligently

A simple way to think about AI:

> If a task requires human-like thinking and a machine can perform it, it is considered Artificial Intelligence.

# Artificial Intelligence (AI)

## Definition

AI is the broad concept of creating machines that simulate human intelligence.

- Understand language

- Make decisions
- Solve problems

Examples:

- Chatbots
- Self-driving cars
- Voice assistants

---

# Machine Learning (ML)

## Definition

Machine Learning is a subset of AI that allows computers to learn from data instead of being explicitly programmed.

Traditional Programming:

```
Rules + Data
      |
      v
   Program
```

Machine Learning:

```
Data + Examples
       |
       v
   ML Model
       |
       v
 Predictions
```

---

# How Machine Learning Works

Instead of writing every rule manually, we provide examples and allow the model to discover patterns.

Example:

## Spam Detection

Traditional programming:

```
If email contains "free money"
→ Spam
```

Machine Learning:

```
Thousands of emails
        |
        v
Model learns patterns
        |
        v
Predicts spam
```

---

# Types of Machine Learning

Machine Learning has three main methods:

1. Supervised Learning
2. Unsupervised Learning
3. Reinforcement Learning

---

# 1. Supervised Learning

## Definition

Supervised learning trains models using labeled data.

The model learns from examples where the correct answer is already known.

Example:

| Image | Label |
|---|---|
| 🐱 | Cat |
| 🐶 | Dog |

The model learns patterns and predicts new examples.

---

## Key Ingredients

- Labeled data
- Known outcomes
- Prediction or classification

---

## Use Cases

### Spam Detection

```
Email → Spam / Not Spam
```

### Medical Diagnosis

```
Scan → Normal / Abnormal
```

### Customer Churn Prediction

```
Customer → Leave / Stay
```

### House Price Prediction

```
House Features → Price
```

---

# 2. Unsupervised Learning

## Definition

Unsupervised learning uses data without labels.

The model discovers hidden patterns and structures.

Example:

Customer data:

```
Age
Location
Purchases
Interests
```

The model may discover:

```
Group 1 → Frequent customers

Group 2 → Occasional customers

Group 3 → New customers
```

---

## Key Ingredients

- Unlabeled data
- Pattern discovery
- Finding relationships

---

## Use Cases

- Customer segmentation
- Market analysis
- Anomaly detection
- Clustering

---

# 3. Reinforcement Learning

## Definition

Reinforcement Learning allows machines to learn through trial, error, rewards, and penalties.

Example:

AI learning to play a game:

```
Agent takes action
        |
        v
Environment responds
        |
        v
Reward / Penalty
        |
        v
Agent improves
```

---

## Key Elements

## Agent

The learner or decision-maker.

Examples:

- Robot
- Game AI

---

## Environment

The world where the agent operates.

Examples:

- Game environment
- Real world

---

## Reward

Feedback that helps the agent learn better actions.

---

## Applications

- Robotics
- Autonomous vehicles
- Game AI
- Optimization systems
