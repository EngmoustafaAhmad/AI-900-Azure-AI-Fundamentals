# Deep Learning (DL)

## Definition

Deep Learning is a specialized type of Machine Learning that uses **neural networks** inspired by the structure and function of the human brain.

Deep Learning models contain multiple layers of artificial neurons, which is why they are called **"deep" neural networks**.

The deeper the network, the more complex patterns it can learn.

---

## How Deep Learning Works

Deep Learning automatically learns features from data through multiple layers.

Example: Image Recognition

```
Image Input
     |
     v
Detect Edges
     |
     v
Detect Shapes
     |
     v
Recognize Objects
     |
     v
Final Prediction
```

A deep learning model can learn:

- Simple features → edges and colors
- Medium features → shapes and patterns
- Complex features → objects and meanings

# AI vs ML vs DL Comparison

| Technology | Description | Example |
|---|---|---|
| Artificial Intelligence (AI) | The broad field of making machines intelligent | Rule-based chatbot |
| Machine Learning (ML) | AI systems that learn patterns from data | Spam detection |
| Deep Learning (DL) | ML using deep neural networks | Face recognition, ChatGPT |

---

# Real-World Examples

| Technology | Type |
|---|---|
| Email filters detecting spam | Machine Learning |
| Phone Face ID unlocking | Deep Learning |
| Rule-based chatbot | AI (Non-learning) |
| Netflix recommendations | Machine Learning |
| ChatGPT generating text | Deep Learning |

# Key Takeaways

- AI is the largest concept that includes ML and DL.
- Machine Learning allows systems to learn from data.
- Deep Learning is a powerful type of Machine Learning based on neural networks.
- Deep Learning is especially useful for complex data:
  - Images
  - Video
  - Audio
  - Natural language
